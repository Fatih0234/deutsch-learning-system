# Speaking Session — 2026-10-02 — Initial System Design

## Mode

Speaking

## Topic

How to build a German-learning feedback loop around daily life and software development.

## Content summary

The learner explained that they want to use German more actively instead of
treating it only as a separate subject. Software development, Coding Agents,
phone, browser and other daily tools should become part of the learning
environment.

A central goal is to create a feedback loop:

```text
use German → make mistakes → receive feedback → detect recurring patterns
→ practice them → use German again
```

## Important feedback

### 1. je ... desto ...

Observed:

> desto ich spreche, mehr lerne ich Deutsch

Target:

> Je mehr ich spreche, desto mehr Deutsch lerne ich.

### 2. sich anfühlen

Observed:

> Deutsch fühlt mich mehr natural

Target:

> Deutsch fühlt sich für mich natürlicher an.

### 3. Time planning

Natural expressions:

> Ich möchte jeden Tag ein bis drei Stunden fürs Deutschlernen einplanen.

> Ich möchte Deutschlernen zu einer Priorität machen.

### 4. Word order

Observed:

> Gerade ich spreche ...

Target:

> Gerade spreche ich ...
