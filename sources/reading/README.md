# Reading Sources

Store metadata and learning notes for reading material here.

Recommended filename:

```text
YYYY-MM-DD-short-topic.yaml
```

Example:

```yaml
type: reading
title: "Example article"
url: "https://example.com/article"
date_used: 2026-10-05
topic:
  - artificial_intelligence

learner_summary: >
  ...

comprehension:
  understood:
    - ...
  misunderstood:
    - ...

selected_vocabulary:
  - ...
```

Do not copy full copyrighted articles into the repository unless you have the
right to store them. Prefer URL + notes + short excerpts when needed.
