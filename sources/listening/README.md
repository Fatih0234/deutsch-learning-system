# Listening Sources

Store metadata and learning notes for audio/video sources here.

Recommended filename:

```text
YYYY-MM-DD-short-topic.yaml
```

Example:

```yaml
type: listening
title: "Example podcast episode"
url: "https://example.com/podcast"
date_used: 2026-10-06
topic:
  - software_engineering

learner_summary: >
  ...

comprehension:
  understood:
    - ...
  missed:
    - ...

selected_vocabulary:
  - ...
```

Prefer listening before reading a transcript.
